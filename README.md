# 🎬 MotoCine Estudio — Daytona Moto Sport

Crea videos para redes **sin escribir guiones ni hablar con nadie**:

1. Ve a **Issues → New issue → 🎬 Nuevo video** (también desde la app de GitHub en el celular).
2. Elige **formato**, **falla**, **escenario** y **letra correcta**, y presiona **Submit new issue**.
3. En 15–25 minutos aparece un comentario con **el video para descargar**, la hoja de cuadros y las notas de los
   revisores (viralidad, atención, diseño, sincronía). Te llega la notificación al celular.

Cada formato usa una plantilla con las reglas de viralidad (`references/viral.md`). Las fallas salen del catálogo
(`catalogo/fallas/`): cada una trae sus datos verificados, su sonido y su escena "por dentro".

El motor se mantiene en el repositorio privado `motocine-ai` y se copia aquí con
`python -m motocine publicar-estudio`. No edites el motor aquí: los cambios se pierden en la próxima copia.
